The Token Tax

Curate, or pay per token

Every token you load, you pay for. Even with caching, the only way to scale is curation.

Naive RAG
100K tokens · no cache
~$0.31 / query
~$310K / day at 1M queries
Cached RAG
100K tokens · best practice today
~$0.04 / query
~$40K / day at 1M queries
Curated context
~580 tokens · assemble_context()
~$0.0095 / query
~$9.5K / day at 1M queries
32× vs naive  ·  4× vs cached
Why TiDB makes curation realistic
On a fragmented stack
  • Pull from SQL DB, vector DB, search DB, analytics DB
  • Merge + rank in app code
  • 4 round trips · partial-failure surface
On TiDB
  • One assemble_context() call
  • Rows + vectors + search + analytics in one ACID query
  • 1 round trip · no partial-failure risk

Even RAG done right costs 4× more than curated memory. The win is curation, not capacity.
